**Immediate Flood Response – Website
Official website for Immediate Flood Response, providing 24/7 emergency flood restoration, water extraction, structural drying, mould treatment, and water‑damage repair services across Sydney.
This repository contains the full website codebase, including the main service pages, suburb‑based SEO pages, and ongoing updates. The site is built with HTML, CSS, and JavaScript, and deployed using GitHub Pages with a custom domain.
---
**Features
• Responsive, mobile‑friendly design
• Main service pages (Home, About, Services, Contact)
• Suburb‑specific SEO landing pages
• Fast static hosting via GitHub Pages
• Easy updates and version control
• Custom domain integration**
